## 7. 검증

| 이름 | 코드·설정 이름 | 뜻 | 보는 곳 |
|---|---|---|---|
| 점수표 | `scorecard` | 결과가 얼마나 지구다운지, 규칙을 어기지 않았는지 재는 항목 표 | 스튜디오 개요 탭 |
| forced | `kind: forced` | 입력으로 정한 값이 그대로 나오는 지표. 맞아도 '지구답다'는 근거가 아님 | 점수표 |
| emergent | `kind: emergent` | 입력에 없던 성질이 결과로 나온 지표. '지구답다'는 근거로 쓰는 것은 이것뿐 | 점수표 |
| check | `kind: check` | 꼭 지켜야 하는 규칙(물이 모두 바다에 닿음, 거꾸로 흐르는 강 0). 어기면 불합격 | 점수표 |
| 기준선 | baseline | 진짜 지구 자료(ETOPO 등)를 같은 코드로 잰 점수. 우리 행성과 견줄 잣대 | [roadmap.md](roadmap.md) |
| 대조군 | control | 노이즈 지형이나 요소 하나를 끈 행성. 무엇이 효과를 냈는지 가르는 데 씀 | [compare.md](compare.md) |
| golden 대조 시험 | `tests/golden` | Python 판이 만든 결과와 C# 결과가 비트까지 같은지 보는 시험 | [csharp_port.md](csharp_port.md) |
| 결정성 | determinism | 같은 설정과 시드면 어느 컴퓨터, 몇 개의 코어로 돌려도 결과가 같음 | [conventions.md](conventions.md) |

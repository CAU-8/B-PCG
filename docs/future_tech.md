# 앞으로 도입할 기술

지금 코드(학습 전 생성 파이프라인, 2026-10-02 기준)에서 보이는 빈틈마다, 다음에 들여올 기술과 그 기술이 됐다고 말할 합격 지표를 정합니다. 일정과 역할은 [roadmap.md](roadmap.md)와 설계도 8장을 따르고, 둘이 다르면 설계도가 맞습니다. 빈틈의 근거는 [pipeline.md](pipeline.md) 14장 '알려진 빈칸'과 earth_v2 실행(laptop 프로필) 결과입니다.

## 2. 거시 (L0, 칸 약 20~78 km)

| 사슬 | 지금 보이는 것 (빈틈) | 들여올 기술 (제안) | 합격 지표 |
|---|---|---|---|
| 2 | 강의 오목도 θ, 가파름 k_s, 산비탈 한계 S_crit 가 문헌값과 손 보정값. 보정할 때 n = 2, 산맥 띠 폭, S_crit 표를 손으로 바꿨음 | **데이터로 맞추기.** ① GLO-90 파일럿 40개 유역에서 유출로 바꾼 χ(χQ)로 θ, ② OCTOPUS 침식률과 k_sn 으로 E = K·k_sn^n 회귀(n > 1 허용) → '융기·비·암석 → k_s' 지도, ③ 실제 지구 입력(ETOPO 기준선)으로 솔버를 돌려 경사·가파름·Hack·고도 분포가 맞도록 k_ref·S_crit 를 최소화로 맞춤(넬더-미드 또는 CMA-ES, 매개변수 2~4개). 결과는 `configs/learned/` | 숲이 적은 산지 유역의 θ 분포 보고, k_s 회귀 R² 와 지역별 차이 보고, 진짜 지구를 넣었을 때 큰 강 상류 면적 오차 ≤ 10%. 손 보정값과 학습값의 차이를 표로 |
| 1 | 해양저 나이에 쐐기 모양 흔적 (해령에서 잰 거리로 나이를 근사) | **흐름선 나이.** 판의 오일러 극 둘레 작은 원을 따라 해령까지 거슬러 간 거리 ÷ 확장 속도. 판 경계가 바뀌지 않는 한 번 계산 | Seton 2020 나이-면적 분포와 같은 축 비교, 쐐기 흔적(나이 등고선이 해령과 평행하지 않은 곳) 0 |
| 1 | 산맥 옆 분지, 해구 바깥 융기가 없음 (지각평형은 대륙-해양 경계의 Airy 만) | **얇은 판 굽힘.** 탄성 두께 Te 의 판이 하중(산맥, 퇴적물, 섭입판)으로 굽는 식을 면마다 FFT 로 풀고 고스트 칸으로 잇기. gFlex 등 공개 코드는 라이선스 확인 뒤 비교용으로만 | 산맥 옆 전륙분지 깊이 1~4 km, 해구 바깥 융기 수백 m 범위. 면 경계 띠와 안쪽의 통계가 같음 |
| 1·2 | 바다로 나간 퇴적물이 사라짐, 대륙붕 넓이가 결과가 아님 | **대륙붕 퇴적.** 출구 퇴적물 Qs 를 해안에서 바다 쪽으로 확산(선형 확산 정상상태)해 쌓기 | 대륙붕 평균 너비와 ETOPO 비교 (단서: 해수면 변동 없음) |
| 사슬 밖 | 강수가 위도 띠 + 노이즈뿐, 산맥 뒤 비그늘이 없음 | **지형성 강수.** Smith & Barstad 2004 선형 모델을 면마다 FFT 로 (바람은 위도 띠 바람) | 산맥 양쪽 강수 비, CHELSA 와 같은 축 비교 |
| 검증 | 면 경계 이음새를 격자 정렬 지수로만 봄 | **회전 시험.** 입력(판, 노이즈)을 구 위에서 돌려 다시 만들고 통계를 비교 | 회전 전후 고도 분포·하천 통계 차이가 시드끼리의 차이 안 |

## 3. 중간 (히어로 L2, 25 m)

| 사슬 | 지금 보이는 것 (빈틈) | 들여올 기술 (제안) | 합격 지표 |
|---|---|---|---|
| 2 | 히어로 칸의 30%가 물길 방향 진동으로 고정됨. 거친 격자 먼저 풀기로 169회에 멈추지만 진동 칸은 남음 | **솔버 가속.** Tzathas 2024 의 멀티그리드(내려가는 절반까지), 고정점 반복에 앤더슨 가속, 진동 칸에는 여러 방향 흐름(MFD)으로 방향을 나눠 결정. Tzathas 코드는 비상업 라이선스라 논문만 보고 다시 구현 | 고정 칸 < 1%, 반복 수와 시간 보고, fastscapelib 과 평균 고도·고도 분포 차이 < 5% |
| 2 | 선상지 판정(경사가 4배 줄면)이 n = 1 기준이라 n = 2 에서 평면 히어로에 선상지가 없음 | **n 에 맞춘 판정.** 경사 비 대신 깎이는 힘의 비(E ∝ S^n)로: 경사 비 ≥ 4^(1/n) | 평면 히어로에서 선상지 생김, 실제 히어로 선상지 칸 수 변화 보고 |
| 2·3 | '가파르면 맨 암반' 규칙(0.8)이 새 S_crit 이상이라 거의 안 걸림 | **흙 생산과 깎임의 균형.** Heimsath 흙 생산률보다 깎임이 빠르면 맨 암반(E > P₀), 기울기 문턱은 S_crit 의 비율로 | 맨 암반 비율과 경사의 관계가 DiBiase 2012 등 산지 관측과 같은 모양 |
| 3 | 육지 91~96%에서 지하수면이 지표에 닿음 (지구 22~32%, Fan 2013) | **2D 지하수 방정식.** 듀피 가정의 정상상태 ∇·(T∇h) + R = 0 을 강·호수 수위를 경계로 희소 선형계로 풀기 (scipy 희소 해법, 크면 멀티그리드). 투수성은 암석 표(Gleeson 2011) | 지하수가 지표에 닿는 땅 비율이 22~32% 범위, 물 수지 오차 ≤ 1e-3, 'z_gw ≤ max(지표, 수면)' 위반 0 |
| 3 | 동굴 입구가 너무 많고, 아래층 동굴이 지하수면에 붙어 강가에서 지표를 뚫음 | **동굴 위치 규칙.** ① 아래층은 지하수면 아래 일정 깊이(잠긴 통로), 위층은 옛 기준면(강이 깎아 내려가기 전 높이), ② 입구는 골짜기가 동굴 층을 자른 곳 중 상류 면적이 큰 몇 곳만, ③ 동굴 그물은 KarstNSim 처럼 입구와 샘을 잇는 그래프로 (코드 라이선스 확인 뒤 비교용) | 동굴 ⊂ 녹는 암석 100%, 입구 밀도(곳/km²)를 실제 카르스트 지역 범위와 비교, 지표 구멍 비율 < 0.5%, 동굴이 입구와 이어지는 비율 보고 |
| 사슬 밖 | 숲이 없음 | **식생 규칙.** AfriSAR 에서 배운 '건조도·경사·지하수 깊이 → 나무 높이' 규칙으로 엔진에 나무 배치 | 나무 높이 분포를 AfriSAR 와 같은 축 비교 |

## 4. 미시 (회랑 L3, 복셀 1~2 m, 엔진)

| 사슬 | 지금 보이는 것 (빈틈) | 들여올 기술 (제안) | 합격 지표 |
|---|---|---|---|
| 3 | 동굴 메시 한 덩어리 104 MB, 삼각형 390만 개. 편집기 첫 가져오기가 느림 | **조각 glb + 단순화 + LOD.** 동굴을 64 복셀 조각마다 따로 쓰고, meshoptimizer(gltfpack, MIT)로 단순화, 조각마다 거리별 LOD. 엔진은 가까운 조각만 불러옴 | 회랑 동굴 파일 합 < 30 MB, 불러오기 < 5 초, 데모 기기 60 fps |
| 2·3 | 단면 칼과 노클립으로 보기만 함, 팔 수 없음 | **실행 중 복셀.** godot_voxel(Zylann, MIT)의 VoxelLodTerrain 에 우리 3D 함수(지표 SDF + 동굴 SDF + 재질)를 미리 구운 복셀 블록으로 넣고 파기 허용. 10/21 관문에서 Godot 4.7 용 GDExtension 판이 되는지 headless 로 먼저 확인 | `ClassDB.class_exists("VoxelLodTerrain")`, 파낸 단면의 재질이 strata.u8 과 같은 비율 > 99%, 60 fps |
| 사슬 밖 | 주변은 25 m 높이맵 한 장(32 km), 그 밖은 비어 있음 | **GPU 클립맵 지형.** Terrain3D(MIT) 같은 클립맵 지형으로 L0 높이를 수백 km 까지 깔고 히어로·회랑을 그 위에 겹침. 이음새는 안개와 치마로 | 지평선까지 빈 곳 없음, 히어로 경계 높이 차 < 칸 크기 |
| 사슬 밖 | 정밀도 때문에 회랑 기준점 근처만 다님 | **기준점 옮기기.** 플레이어가 멀어지면 세계를 통째로 옮겨 원점 다시 잡기 (float32 유지) | 원점에서 30 km 떨어져도 떨림 없음 (위치 단위 < 1 mm) |
| 사슬 밖 | 행성 전체를 볼 수 없음 | **궤도 보기.** 큐브스피어 면마다 쿼드트리 LOD 메시, 면 텍스처(고도, 판, 해양저 나이, 강수)를 바꿔 보기, 히어로 위치 표시 | 궤도 → 히어로까지 끊김 없는 이동 영상 |
| 2·3 | 지형 색이 단색 위주, 암석 질감 없음 | **암석별 재질.** 재질 번호로 삼면 투영(triplanar) 텍스처 배열, 강·호수에 유량으로 만든 흐름 지도(flow map) | 블라인드 비교에서 노이즈 행성과 구분되는 비율 (여유, 참여 장치) |
| 3 | 동굴 안이 하늘 빛으로 고르게 밝음 | **동굴 조명.** 회랑에 VoxelGI 또는 SDFGI, 입구 빛 새어 들기, 안개 부피 | 동굴 깊이에 따라 밝기가 줄어듦 (단계별 화면 캡처) |

## 6. 확인할 것

- Tzathas 2024 코드와 KarstNSim, gFlex 의 라이선스: 가져다 쓰지 않고 비교용으로만 돌릴 수 있는지.
- godot_voxel 의 Godot 4.7 용 GDExtension 판 유무 (10/21 관문).
- Terrain3D 가 Godot 4.7.2 에서 도는지와 우리 높이맵 형식(.bin float32)을 그대로 받는지.
- Fan 2013 과 Gleeson 2011 원문 값 (지하수 방정식의 상수).
